# 云妆 AI 知识助手 · 交付演示

本仓库用于盘古星火客户演示：需求 → 任务 → 本体 → 编码。所有医生、患者与品牌资料均为虚构模拟数据。

演示切片：医生身份与患者归属校验、患者切换、有效品牌知识检索、带引用回答、医生确认归档；品牌管理员只读查看患者资料。

参考云妆需求与技术方案 v1，演示不连接原后台、小程序、真实患者库，不执行生产部署。完整范围仍需另行评审。

代码已在 `codex/yunzhuang-demo` 分支产出，包含可本地运行的标准库 API、模拟资料、中文单页 UI 和隔离权限回归测试。

## 本地运行

```bash
python3 app.py
# 浏览器访问 http://127.0.0.1:8000/
```

无需安装依赖。模拟身份：医生 D001 / D002、品牌管理员 A001，首次进入页面时选择。

## 验证

```bash
python3 -m unittest -v
```

接口、权限矩阵、测试范围与真实限制详见 [`docs/交付说明.md`](docs/交付说明.md)。
